# Bugfix

**先复现，再动刀。** 只改与根因直接相关的代码。骨干见 `../references/bug-fix.md`。

匹配：修 bug、回归、线上/本地复现后的最小修复。还在摸原因时先走 `research.md`。

## 步骤（原样抄到 todo）

1. **复现。** 写下复现路径与失败现象；没有复现不要猜补丁。
2. **定位根因。** 证据指向哪一层；区分诱因与根因。不确定就回 `research.md`。
3. **最小修复。** 只改直接相关代码。禁止顺手重构，禁止直接改生产环境配置。
4. **补最小验证并留证据。** 用复现路径证明修掉了；「编译过」不算。细节可接 `test.md`。
5. **过代码风格门。** 对照 `../references/code-style.md` 扫修复 diff；禁止顺手重构 / 注释噪声。
6. **决定要不要沉淀。** 对照 `reflect.md` 的复杂度/根因门槛，不够深就 `skip: 局部小修`。

**回复：** 复现路径、根因、改了什么（为何最小）、验证证据、风格门、是否需要 reflect。
